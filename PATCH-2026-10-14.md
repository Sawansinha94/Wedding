# Changes

- Guest approved profile payload now contains **all non-private fields**, instead of a fixed subset, when approved_for_guests=true, share_with_subject_after_verified_login=true and review_status=approved.
- Private notes and familiarity question answers are not disclosed based only on name/guessable question; this flow is not secure authentication.
- Concierge passes the resulting profile JSON into its system prompt on every request carrying the personalized session token.
- Site language switching no longer calls `/api/site/translate` or an LLM. Only bundled dictionaries are used, with synchronous immediate application.
- `TRANSLATION-COVERAGE-TODO.txt` is an audit list. Any untranslated strings must be added to the offline catalog in all languages. This patch does **not** claim 100% translation coverage.
- Build or complete `assets/js/29-static-catalog.js` offline before deployment.
